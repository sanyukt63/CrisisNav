# Incident Checklist

Use this checklist when a release affects emergency guidance or offline behavior.

- Verify the application starts successfully.
- Verify core protocols load while online.
- Disable connectivity and reload.
- Confirm cached protocol content remains accessible.
- Test navigation between protocol steps.
- Check language switching.
- Check keyboard and touch interactions.
- Reconnect and verify normal updates resume.

For real emergencies, CrisisNav must never be presented as a replacement for official emergency services or public-safety instructions.
