# Accessibility Checklist

Emergency guidance should remain usable by as many people as possible.

- Maintain clear heading structure.
- Keep controls keyboard accessible.
- Provide visible focus states.
- Use descriptive labels and link text.
- Do not communicate critical status through color alone.
- Provide text alternatives for meaningful icons.
- Keep instructions concise and easy to scan.

Accessibility testing should be part of feature review, especially for navigation and protocol screens.
